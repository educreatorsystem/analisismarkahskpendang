# Sistem Analisis Peperiksaan – SEKOLAH KEBANGSAAN PENDANG

Versi yang dikemas kini pada 5 November 2026. Versi ini menggunakan Google Sheet ID, Apps Script dan tiga URL CSV yang terkini seperti diberikan oleh pengguna, bersama lencana SK Pendang baharu.

## GitHub Pages
1. Muat naik fail `index.html` ke root repositori GitHub.
2. Dalam Settings > Pages, pilih Deploy from a branch, `main`, `/ (root)`.
3. Buka pautan GitHub Pages yang diberikan setelah deploy selesai.
4. Untuk Google Sites, gunakan Insert > Embed > By URL dengan pautan GitHub Pages tersebut.

Lencana sekolah dipaparkan menggunakan URL imej luaran, jadi perlu ada sambungan Internet.
Sambungan Google Sheets dan Apps Script serta proses simpan markah perlu diuji dalam pelayar selepas diterbitkan.
